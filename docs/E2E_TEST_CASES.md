# 英语单词速记 App - 端到端测试用例

**文档版本**：v1.0  
**创建日期**：2026-08-27  
**测试环境**：iOS Simulator (iPhone 16 Pro) + Expo Go  
**测试状态**：✅ 全部通过  

---

## 一、测试概述

### 1.1 测试目标

验证英语单词速记 App 的核心功能模块，确保：
- 所有页面正常加载和显示
- 用户交互流程完整
- 数据加载和展示正确
- 权限控制正常工作

### 1.2 测试范围

| 模块 | 功能点 | 优先级 |
|---|---|---|
| 首页 | 入口展示、进度显示、今日目标 | P0 |
| 词汇量测评 | 测评入口、测评说明、结果展示 | P0 |
| 体验课 | 课程展示、每日任务、进度追踪 | P0 |
| AI 解析 | 错词选择、AI 分析、短文入口 | P1 |
| 错词本 | 错词列表、状态筛选、空状态处理 | P1 |
| 学习统计 | 数据展示、趋势图表、本周总结 | P1 |
| 复习功能 | 单词卡片、发音播放、评分系统 | P0 |
| 设备管理 | 设备列表、设备限制、当前设备 | P2 |
| 学习报告 | 报告预览、学习建议、PDF 导出 | P2 |
| 正式课程 | 课程等级、单元列表、锁定状态 | P1 |
| 个人中心 | 用户信息、功能入口、设置 | P1 |

### 1.3 测试环境

- **设备**：iPhone 16 Pro (iOS Simulator)
- **系统**：iOS 17.0
- **框架**：Expo SDK 57
- **服务**：Metro Bundler (端口 8081)
- **数据**：本地演示模式 + 云端 Supabase 模式
