## 二、背景与目标

### 2.1 项目背景

面向中学生和大学生的英语单词记忆 App，核心卖点：

1. **词汇量测评**：通过 CAT 自适应测试精准定位用户当前词汇量
2. **个性化课程**：根据测评结果自动匹配学习内容
3. **间隔复习**：基于科学记忆算法（SM-2 变体）安排复习
4. **AI 辅助**：生成错词解析、短文语境，提升记忆效率
5. **教学管理后台**：支持机构（学校/培训机构）批量管理学生和查看数据

### 2.2 产品目标

| 目标维度 | 具体指标 |
|---|---|
| 核心价值 | 帮助用户在 3~6 个月内完成 3000~6000 词的高效记忆 |
| 体验目标 | 3 天体验课内让用户感受到"记得住、有节奏" |
| 商业目标 | 体验课→正式课转化率 ≥ 15%（建议值，待产品确认） |
| 留存目标 | 7 日留存 ≥ 40%，30 日留存 ≥ 20%（建议值，待产品确认） |

### 2.3 目标用户

| 用户角色 | 特征 | 核心需求 |
|---|---|---|
| C 端学生用户 | 中学生 / 大学生，年龄 14~24 | 高效记单词、测评词汇量、查看进步 |
| 机构管理员 | 学校教师 / 培训机构负责人 | 批量管理学生、查看班级数据报表 |
| 超级管理员 | 平台运营人员 | 词库管理、用户管理、系统配置 |

### 4.2 课程状态机（v2.0 新增）

**状态定义**：

| 状态 | 说明 |
|---|---|
| `NOT_STARTED` | 课程未开始 |
| `IN_PROGRESS` | 正在学习中 |
| `PAUSED` | 主动暂停（支持恢复） |
| `INTERRUPTED` | 异常中断（网络断开等，支持恢复） |
| `COMPLETED` | 正常完成 |
| `GRADUATED` | 达到毕业标准 |
| `EXPIRED` | 体验课过期（未在 3 天内完成） |

**状态转移规则**：

```
NOT_STARTED ──[开始学习]──► IN_PROGRESS
IN_PROGRESS ──[用户暂停]──► PAUSED
IN_PROGRESS ──[网络中断/异常]──► INTERRUPTED
IN_PROGRESS ──[完成所有单元]──► COMPLETED ──[达到毕业标准]──► GRADUATED
PAUSED ──[恢复学习]──► IN_PROGRESS
INTERRUPTED ──[恢复/重连]──► IN_PROGRESS
EXPIRED（仅体验课）──[重新进入]──► NOT_STARTED
```

### 4.3 断点恢复机制（v2.0 新增）

用户中断学习后恢复时，系统需要：

1. **保存当前学习位置**：记录已完成的单词、当前学习进度百分比
2. **保存答题状态**：记录每个单词的当前答题状态（已学习/学习中/待复习）
3. **保存学习数据**：已用时长、正确率统计
4. **恢复策略**：
   - 中断 < 5 分钟：从当前单词继续
   - 中断 5 分钟 ~ 24 小时：回到当前单元开头，重新确认记忆
   - 中断 > 24 小时：建议先完成当日复习任务，再继续新词

> **待产品确认**：断点恢复的具体时间阈值和恢复策略是否需要可配置？

## 五、功能需求

### 5.1 词汇量测评模块

#### 5.1.1 测评流程

1. 用户进入测评页面，选择测评场景（可选：默认/中考/高考/四级/六级）
2. CAT 引擎按规则出题，用户答题
3. 达到停止条件后，输出测评结果
4. 结果展示：词汇量估计值 + Band 等级 + 能力描述

#### 5.1.2 CAT 测试规则（v2.0 完善）

**基础规则**：

- 共 7 个 Band（Band 0 ~ Band 6），每个 Band 对应一组难度词库
- 从 Band 2（默认起点）开始出题
- 连续答对 3 题 → 当前 Band + 1（升档）
- 连续答错 2 题 → 当前 Band - 1（降档）

**停止条件**（满足任一即停止）：

1. 已出题 ≥ 50 题（最低题量）
2. 已出题 ≥ 30 题 且 置信区间宽度 ≤ 阈值（建议 SEM ≤ 0.3，待产品确认）
3. 已出题 ≥ 80 题（最高题量，防止无限测试）

**Band 边界处理**：

- 当 Band = 0 时，连续答错 2 题仍保持 Band 0（不继续下降）
- 当 Band = 6 时，连续答对 3 题仍保持 Band 6（不继续上升）
- 在边界 Band 的答题同样计入停止条件的题数统计

**每 Band 出题规则**：

- 每个 Band 最少出 5 题（确保采样充分）
- 当升档/降档发生时，立即从新 Band 题库中抽题
- 同一个单词在一次测评中不重复出现

**最终词汇量计算**（v2.0 新增）：

```
词汇量估计值 = Σ(各 Band 词汇量 × 该 Band 正确率权重)
置信区间 = 基于 IRT 模型或 Rasch 模型的标准误差计算
```

> **待产品确认**：
> 1. 是否使用 IRT（Item Response Theory）模型计算置信区间？还是简化为"±固定百分比"？
> 2. 各 Band 对应的具体词汇量范围是多少？（例如 Band 0 = 0~500 词，Band 6 = 5000~6000 词）
> 3. SEM 阈值设定为多少？建议 0.3

#### 5.1.3 伪词设计（v2.0 新增）

**用途**：伪词用于 CAT 测试中的干扰项，帮助判断用户是否真正认识某个词。

**伪词生成规则**：

1. 拼写合法：符合英语语音规则（例如 "blenit" 合法，"zxqwl" 不合法）
2. 无实际意义：不能是任何已知英语单词的变体
3. 长度匹配：与目标单词长度相近（±2 个字母）
4. 每题 4 个选项：1 个正确答案 + 3 个伪词（同难度级别）

**伪词库管理**：

- 预置伪词库：至少 2000 个伪词，覆盖各难度级别
- 每次出题时从伪词库中随机抽取
- 伪词库需要定期审核，确保不产生真实单词

> **待产品确认**：
> 1. 伪词是否需要人工审核？还是可以通过规则自动生成 + 筛选？
> 2. 是否需要支持"都不认识"选项？（即用户可以选"我不知道"）

#### 5.1.4 测评结果展示

```
┌─────────────────────────────┐
│  你的词汇量评估结果          │
│                             │
│  ┌─────────────────────┐    │
│  │  词汇量：4,200 词    │    │
│  │  置信区间：3,800~4,600│   │
│  └─────────────────────┘    │
│                             │
│  能力等级：Band 4           │
│  描述：可应对大学四级水平    │
│                             │
│  [查看详细分析]              │
│  [开始体验课]                │
└─────────────────────────────┘
```

### 5.2 体验课模块

#### 5.2.1 体验课规则

- 时长：3 天（从首次进入开始计算）
- 词量：约 100 个单词
- 学习模式：新词学习 + 即时复习
- 免费，无需付费

#### 5.2.2 体验词库匹配（v2.0 新增）

**匹配规则**：

1. 体验课词库从用户测评结果对应的 Band + 相邻 Band 中抽取
2. 优先选择高频、实用的单词
3. 词库分布建议：
   - 70% 来自用户当前 Band
   - 20% 来自用户当前 Band - 1（巩固）
   - 10% 来自用户当前 Band + 1（挑战）
4. 体验课词库不与正式课词库重复（正式课解锁后重新分配）

**特殊场景**：

- 用户未完成测评 → 使用默认 Band 2 的体验词库
- 用户测评结果异常（如全部答对/全部答错）→ 使用默认词库 + 提示重新测评

> **待产品确认**：体验课词库是否需要支持后台手动配置？

#### 5.2.3 体验课到期处理

- 3 天到期后，体验课不可继续学习
- 显示"体验已结束，解锁正式课继续学习"
- 用户的学习记录保留 7 天，7 天后清理

### 5.3 正式课程模块

#### 5.3.1 课程结构

```
正式课程
├── Level 1（对应 Band 2 词汇）
│   ├── Unit 1：20 新词 + 穿插复习
│   ├── Unit 2：20 新词 + 穿插复习
│   ├── ...
│   └── Unit N：20 新词 + 穿插复习
├── Level 2（对应 Band 3 词汇）
│   └── ...
└── Level M（对应 Band 6 词汇）
```

#### 5.3.2 每日学习流程

```
进入课程
    │
    ▼
【新词学习】每次 20~40 个新词（可配置）
    │
    ├── 每学 5 个新词 → 插入 2~3 个穿插复习词
    │
    ▼
【当日复习任务】（如有）
    │
    ├── 错词池中的词
    ├── SM-2 到期的词
    │
    ▼
【完成当日学习】
```

#### 5.3.3 单词学习模式（4 阶段）

每个单词的学习过程：

| 阶段 | 内容 | 交互 |
|---|---|---|
| 1. 认知 | 展示单词 + 音标 + 音频 + 中文释义 | 用户浏览 |
| 2. 测试 | 展示单词，用户选择正确释义（4 选 1） | 答题 |
| 3. 巩固 | 展示中文释义，用户拼写/回忆英文 | 可选（v1.0 暂不实现） |
| 4. 确认 | 展示正确答案，用户自评"认识/模糊/不认识" | 确认 |

#### 5.3.4 穿插复习规则

- 每学 5 个新词，插入 2~3 个复习词
- 复习词来源（优先级从高到低）：
  1. 当日错词池中的词（优先强化）
  2. SM-2 算法标记为"即将到期"的词
  3. 当前 Level 内随机选择
- 复习词不计入当日新词进度

### 5.4 复习模块

#### 5.4.1 每日复习

- 每天首次打开 App 时提示当日复习任务
- 复习任务来源：
  1. 错词池中所有单词
  2. SM-2 算法计算出"今日需复习"的单词
- 每日复习量建议：30~60 个单词（可配置）
- 用户可选择"稍后复习"（推迟到当天晚些时候）

#### 5.4.2 SM-2 算法与复习间隔（v2.0 完善）

**SM-2 基本规则**：

```
新单词首次正确：间隔 = 1 天
第二次正确：间隔 = 6 天
之后每次正确：间隔 = 上次间隔 × 复习因子
答错：重置间隔为 1 天，复习次数归零
```

**复习因子计算**：

```
复习因子 = 2.5 + (0.1 × (用户正确率 - 60%))
// 修正范围：1.3 ~ 3.0
// 正确率 100% 时因子 = 3.0（间隔增长最快）
// 正确率 60% 时因子 = 2.5（标准）
// 正确率 < 60% 时因子 = 1.3（间隔增长最慢）
```

**易度评分（Ease Factor）**：

用户答题后，系统根据以下因素自动调整易度评分：

| 用户表现 | 易度调整 |
|---|---|
| 答对 + 选择"认识" | +0.1 |
| 答对 + 选择"模糊" | 不变 |
| 答错 | -0.2 |
| 超时未答（> 30 秒） | 视为答错 |

#### 5.4.3 进阶复习

当用户完成当前 Level 的 70% 以上新词后，触发进阶复习：

- 回顾整个 Level 的所有单词
- 重点标记正确率 < 80% 的单词
- 进阶复习不占用每日学习时间

#### 5.4.4 错词池防死循环机制（v2.0 新增）

**问题**：如果用户始终记不住某些单词，会导致这些词反复出现在复习任务中，形成"死循环"。

**解决方案**：

1. **降级标记**：连续 5 次答错同一单词 → 标记为"困难词"
2. **复习策略调整**：
   - 困难词的复习间隔固定为 3 天（不再使用 SM-2 动态计算）
   - 困难词在复习任务中的占比上限为 20%（避免占据所有复习量）
3. **最终处理**：
   - 连续 10 次答错 → 从当前复习任务中移出，放入"长期记忆区"
   - 长期记忆区的词每 30 天出现一次
4. **用户干预**：
   - 用户可手动将某单词标记为"已掌握"（从错词池移除）
   - 用户可手动将某单词标记为"重点强化"（增加复习频率）

> **待产品确认**：连续答错次数阈值（5 次 / 10 次）是否需要可配置？

### 5.5 毕业规则（v2.0 完善）

**毕业条件**（需同时满足）：

1. 完成所有 Level 的新词学习
2. 当前 Level 的单词正确率 ≥ 85%（可配置）
3. 错词池中无"未处理"的单词（所有错词至少复习过 1 次）
4. 完成至少 1 次进阶复习

**毕业流程**：

```
满足毕业条件
    │
    ▼
系统提示"恭喜达到毕业标准"
    │
    ▼
生成毕业证书（可下载/分享）
    │
    ▼
生成学习报告（总学习量、正确率变化、词汇量变化曲线）
    │
    ▼
可选：导出 PDF 报告
```

**SM-2 / 毕业规则冲突处理**：

- 原问题：SM-2 算法可能要求用户持续复习已"毕业"的单词
- 解决方案：毕业时冻结所有 SM-2 计划，不再安排复习
- 但用户可在"复习模式"中主动查看已毕业的单词

### 5.6 错词管理模块

#### 5.6.1 错词收集

以下情况的单词进入错词池：

1. 测试中答错
2. 复习中答错

## 七、异常与边界处理

### 7.1 网络异常

| 场景 | 处理方式 |
|---|---|
| 答题时断网 | 答案暂存本地，恢复后批量上传 |
| 测评中断网 | 保存已完成题目，允许重新测评或继续 |
| 加载词库失败 | 展示缓存的词库，后台静默重试 |
| 语音加载失败 | 跳过语音播放，显示"语音加载中" |

### 7.2 账号异常

| 场景 | 处理方式 |
|---|---|
| 换设备登录 | 学习数据从服务端同步 |
| 设备超限 | 提示解绑旧设备 |
| 账号被禁用 | 提示"账号已被禁用，请联系管理员" |
| 手机号更换 | 支持换绑（需旧手机号验证） |

### 7.3 数据异常

| 场景 | 处理方式 |
|---|---|
| 词库数据缺失 | 降级使用缓存词库，后台告警 |
| 语音文件缺失 | 跳过语音，展示文字 |
| AI 生成失败 | 展示预生成的备用内容 |
| 测评数据异常 | 标记异常，允许用户重新测评 |

### 7.4 并发异常

| 场景 | 处理方式 |
|---|---|
| 多设备同时学习 | 以最后一次同步为准，冲突数据合并 |
| 服务端数据冲突 | 服务端数据优先，本地冲突数据标记待处理 |

### 附录 B：SM-2 算法详细公式

```
EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))

其中：
- EF' = 新的易度因子
- EF = 当前易度因子
- q = 用户评分（0-5）
  - 5: 完美回答
  - 4: 正确回答，有些犹豫
  - 3: 正确回答，但很困难
  - 2: 错误回答，但看到答案后觉得"我应该知道"
  - 1: 错误回答，看到答案后想起来了
  - 0: 完全不记得

间隔计算：
- I(1) = 1
- I(2) = 6
- I(n) = I(n-1) × EF（n ≥ 3）
```
